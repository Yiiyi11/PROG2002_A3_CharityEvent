Technology stack

Server side

Node.js 18, Express, mysql2 connection pool, RESTful API with full CRUD and parameterised SQL.

Client side

HTML5, CSS3, JavaScript, AngularJS 1.8 controllers, services, directives and two single-page applications.

Data and APIs

MySQL 8 relational schema with foreign keys, plus the external Open-Meteo weather API.
