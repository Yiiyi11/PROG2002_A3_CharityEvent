How the search works

  1. The form builds a query string (?date=&location=&category_id=).
  2. The Express endpoint adds one SQL condition per supplied filter.
  3. Values are bound as parameters, so the query cannot be injected.
  4. Suspended events are always excluded from public results.
ℹ️ Dates are compared with DATE(event_date) = ?, so a single day matches every event happening on that day regardless of the time.
