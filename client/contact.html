Frequently asked

Can I register twice for the same event?

No. The database enforces a unique constraint on the event and email pair, so a second attempt is rejected with a clear message.

How many tickets can I buy?

Up to 10 per registration, and never more than the seats that remain for that event.

Where does the weather data come from?

Open-Meteo, a free public API that needs no key. Forecasts use the latitude and longitude stored for each event venue.
