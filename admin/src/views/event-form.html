Validation rules

  • Name at least 3 characters, description at least 15.
  • Organisation and category must exist in the database.
  • Ticket price and goal cannot be negative.
  • Capacity must be ≥ 1 and ≥ the tickets already sold.
  • Latitude and longitude must be supplied as a pair.
The same rules are enforced again in api/utils/validation.js, so the API cannot be bypassed by calling it directly.
